# 工程測量設計繪圖系統（暫定名稱）

在瀏覽器裡完成工程測量與路線設計：匯入測點、建三角網與等高線、方格法土方、平曲線、縱斷面、橫斷面與平均斷面法土方，輸出 AutoCAD DXF 和 CSV 報表。

- 不用安裝，打開網頁就能用；也能在手機、平板上查看
- **資料只存在使用者自己的瀏覽器（IndexedDB）**，不會上傳到任何伺服器
- 專案可以下載成 `.json` 檔，在別台電腦接著做

## 功能（v0.1 核心版）

| 頁面 | 功能 |
|---|---|
| 專案 | 工程資料（帶入報表抬頭）、開啟／下載專案檔、示範資料 |
| 測點 | 匯入 CSV／TXT（可設欄位順序）、匯入 DXF（點、圖塊、高程文字、等高線、3D 線；支援 Big5 舊檔）、高程檢查（排除 0、-9999）、補點 |
| 地形 | 三角網（最大邊長、邊界限制）、計算範圍邊界、等高線（首曲線／計曲線） |
| 方格土方 | 水平或單向斜面設計面；方格切兩個三角形並依 0 線分開挖填，邊界方格只算邊界內面積 |
| 平曲線 | 座標法、偏角法（ddd.mmss）、圖上定線；R、T、L、E 任給一項互算；切線衝突檢查；整樁與 BC/MC/EC 曲線樁、加樁 |
| 縱斷面 | 由三角網切原地面、縱坡交點、拋物線豎曲線、逐樁設計高與挖填高 |
| 橫斷面 | 路面寬、路拱、挖填邊坡、側溝；放坡與地面線求交；挖填面積；平均斷面法土方與累積土方 |
| 匯出 | AutoCAD R12 DXF（分圖層）、測點表、方格法計算表、平曲線資料表、樁號座標表、土石方數量計算表 |

## 開發

```bash
npm install
npm run dev      # http://localhost:7351
npm test         # 計算核心的單元測試
npm run build    # 輸出到 dist/
```

推送到 GitHub 的 `main` 分支後，`.github/workflows/deploy.yml` 會自動測試、建置並部署到 GitHub Pages。

## 驗證

`tests/` 內的測試用有公式解的情況檢查計算結果，例如：斜面對水平面的挖填量、L 形範圍、角錐體積（誤差 < 0.1%）、Δ=90° R=100 的曲線要素、拋物線豎曲線中距、梯形斷面面積、DXF 寫出後讀回。匯出的 DXF 已用 ezdxf 稽核，沒有格式錯誤。

## 後續規劃

測量計算（3DF、導線、水準、交會、座標轉換）、自動連線成圖、約束三角網（斷線）、3D 地形、超高加寬、構造物與進階組合斷面、出圖排版。
