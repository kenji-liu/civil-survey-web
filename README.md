# 工程測量設計繪圖系統

在瀏覽器裡完成工程測量與路線設計：匯入測點、建三角網與等高線、方格法土方、平曲線、縱斷面、橫斷面與平均斷面法土方，輸出 AutoCAD DXF 和 CSV 報表。

- 不用安裝，打開網頁就能用；也能在手機、平板上查看
- **資料只存在使用者自己的瀏覽器（IndexedDB）**，不會上傳到任何伺服器
- 專案可以下載成 `.json` 檔，在別台電腦接著做
- 內建「範例教學」：14 課操作步驟、6 個練習檔，以及每一課應得到的結果

## 功能

| 頁面 | 功能 |
|---|---|
| 專案 | 工程資料（帶入報表抬頭）、開啟／下載專案檔、示範資料 |
| 測量計算（v0.2） | 控制點資料庫；觀測手簿與 3DF 匯入匯出（斜距＋天頂距／平距＋高差），各廠牌原始記錄檔匯入（Topcon GTS／SSS、Sokkia SDR33、Leica GSI、Nikon DTM、Trimble Geodimeter、Zeiss M5），碎部點計算、轉站點、BS 自由測站（最小二乘後方交會）、99999 前方交會；六種導線（角度閉合差平均分配、羅盤儀法則）；直接水準（開放／閉合／附合、中間視、±C√K 限度檢核，可寫入縱斷面地面高）；兩已知點前方交會；相似／剛體座標轉換 |
| 自動連線（v0.3） | 依測點連線代碼（S.A.M 16 種控制碼：S R L B M A O D T X Z C F E G N，英文碼與數字碼、共點、樓層註記）自動畫出地物線與獨立物符號；可編輯的圖例庫（代碼、名稱、DXF 圖層、線型、符號）；地形線可設為三角網斷線 |
| 測點 | 匯入 CSV／TXT（可設欄位順序）、匯入 DXF（點、圖塊、高程文字、等高線、3D 線；支援 Big5 舊檔）、高程檢查（排除 0、-9999）、補點 |
| 地形 | 三角網（最大邊長、邊界限制、斷線約束）、計算範圍邊界、等高線（首曲線／計曲線）、3D 地形模擬（垂直誇大、中心線與設計線、地物線） |
| 方格土方 | 水平或單向斜面設計面；方格切兩個三角形並依 0 線分開挖填，邊界方格只算邊界內面積 |
| 平曲線 | 座標法、偏角法（ddd.mmss）、圖上定線；R、T、L、E 任給一項互算；對稱克羅梭緩和曲線（TS/SC/CS/ST）；切線衝突檢查；整樁、曲線樁、加樁；依《公路路線設計規範》計算超高（e = V²/127R − f）、超高漸變與 AASHTO 加寬，並檢核最小半徑與緩和曲線長 |
| 縱斷面 | 由三角網切原地面、縱坡交點、拋物線豎曲線、逐樁設計高與挖填高 |
| 橫斷面 | 簡易組合（路面、路拱、挖填邊坡、側溝）或進階組合（構造物單元：路肩、緣石、U 形溝、擋土牆、平台、護岸；繪出條件與運算式 LX LY RW LW RS LS CH GH EH IN TAB；邊坡平台）；套用超高加寬；挖填面積、平均斷面法土方、構造物數量 |
| 出圖 | A3／A2／A1 圖框與標題欄；平面圖依比例分幅、縱斷面圖（含資料表）、橫斷面圖自動排列；輸出 PDF（列印）、SVG、DXF |
| 匯出 | AutoCAD R12 DXF（分圖層）、測點表、方格法計算表、平曲線資料表、樁號座標表、土石方數量計算表 |

## 開發

```bash
npm install
npm run dev      # http://localhost:7351
npm test         # 計算核心的單元測試
npm run build    # 輸出到 dist/
```

推送到 GitHub 的 `main` 分支後，`.github/workflows/deploy.yml` 會自動測試、建置並部署到 GitHub Pages。

## 驗證

`tests/` 內的測試用有公式解的情況檢查計算結果，例如：手冊的連線碼範例（X/Z 直角補點、支距、三點弧、切線弧、F 圓形閉合、T 分叉）、斷線改變三角網、範例教學練習檔與課程描述一致、導線（四已知點、閉合、二已知點旋轉）、水準閉合差分配與限度、自由測站與前方交會由真實幾何反算、斜面對水平面的挖填量、L 形範圍、角錐體積（誤差 < 0.1%）、Δ=90° R=100 的曲線要素、拋物線豎曲線中距、梯形斷面面積、DXF 寫出後讀回。匯出的 DXF 已用 ezdxf 稽核，沒有格式錯誤。

## 已知限制

- 儀器原始檔依手冊附件的格式範例實作；各機型的韌體設定（角度單位、欄位寬度）可能不同，匯入後請核對第一站的觀測值。
- 規範表格以民國 90 年版《公路路線設計規範》為準；設計速率 110、120 km/h 的側向摩擦係數規範未列，沿用 100 km/h 值。
- 進階組合斷面的填方面積量到完成面，含構造物所佔體積；構造物數量另列。
- 自訂構造物單元（自己畫圖形與尺寸標註）、擋土牆展開圖尚未提供。
